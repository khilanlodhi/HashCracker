🔓 Hash Buster
A simple web tool to identify and attempt to reverse hash values using common hash algorithms like MD5, SHA-1, and SHA-256 through dictionary-based lookup.

⚙️ What is Hash Buster?
Hash Buster is a utility tool that helps identify hash types and attempts to reverse them using a local or online wordlist (dictionary attack). It supports basic hash cracking for educational and testing purposes.

🚀 Features
🧠 Hash Type Detection (MD5, SHA-1, SHA-256, etc.)

🔍 Dictionary-based Hash Cracking

🧾 Supports Wordlist Input

🧪 Check multiple hashes in batch
